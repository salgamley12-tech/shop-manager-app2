# مدير المحل

هذا المشروع هو نسخة أولية لتطبيق Android عربي لإدارة محلات البيع بالتجزئة.

## ما الذي تم تنفيذه حتى الآن
- شاشة رئيسية ملخص النشاط.
- إدارة العملاء والموردين.
- إدارة الأصناف والمخزون الأساسي.
- سجل للحركات: مبيعات ومشتريات.
- حفظ البيانات محليًا عبر SQLite.

## الخطوة التالية
الخطوة التالية هي إضافة:
- شاشة تسجيل بيع مع اختيار العميل والصنف والكمية.
- شاشة تسجيل شراء مع اختيار المورد والصنف والكمية.
- تحديث مخزون الأصناف تلقائيًا عند البيع أو الشراء.
- تقارير أكثر احترافية: مبيعات اليوم، الأرباح، العملاء المتأخرين.
- إمكانية تصدير البيانات إلى Excel أو PDF.

## تشغيل المشروع
```bash
flutter pub get
flutter run
```

## بناء APK
```bash

```
