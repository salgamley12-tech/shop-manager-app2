# مدير المحل

تطبيق Android بسيط باللغة العربية لإدارة المبيعات والمشتريات وأرصدة العملاء والموردين. تحفظ البيانات محليًا على الجهاز باستخدام SQLite.

## الوظائف الأولية
- لوحة ملخص للمبيعات والمشتريات والأرصدة.
- تسجيل العملاء والموردين.
- تسجيل فاتورة بيع أو شراء مع المبلغ المدفوع والمتبقي.
- سجل للحركات المسجلة.

## تشغيل المشروع
يتطلب Flutter SDK حديثًا. هذا المستودع يحتوي على مصدر Flutter؛ أنشئ ملفات منصة Android ثم شغّل التطبيق:

```bash
flutter create --platforms=android .
flutter pub get
flutter run
```

لإنشاء APK:

```bash
flutter build apk --release
```

البيانات محلية على الهاتف ولا تتم مزامنتها أو نسخها احتياطيًا تلقائيًا. قبل الاستخدام الفعلي، أضف تصدير/استعادة للبيانات ونسخًا احتياطيًا مناسبًا.
